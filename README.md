Entry for [The Moon Finally Answers Back](https://make.fun/competitions/u-mang-the-moon-finally-answers-back-781a7ec1) — one line in the Moon's voice:

> I waited four billion years for someone to look up and ask — so here I am: yes, I heard you, and yes, I'm still listening.

`main.ts` writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (absolute fallback `/output`), with a guard that the line is non-blank, 1–240 characters, and exactly one line.
